# Курс языки программирования
## *Сюда запишите свою фамилию и номер группы*

### Правила оформления
Для каждой лабораторной работы создается своя папка с номером этой работы, например* **lab01**, **lab02** и так далее.
В эту папку записывается файл README.md с текстом отчета. Доступен файл с формулировками заданий. Ответы можно дописывать в этот файл после формулировок заданий

Если задание предполагает запись некоторых программ, то их надо сохранить во вложенной папке с номером задания.

Каждая работа сдается только очно и только во время практики ровно через две недели после соответствующей лекции. Обратите внимание, что все лабораторные работы сдаются
**только в этот день и больше никогда**.

Допускается использование ИИ для поиска информации, но ответы на вопросы должны быть написаны только самостоятельно. При наличии признаков использования ИИ для записи ответов за
задание начисляются отрицательные баллы в тройном размере. В ответах на вопросы можно ссылаться на фактический материал из достоверных источников. В этом случае 
**обязательно требуется** поставить ссылку. В противном случае такой ответ будет автоматически приравниваться к написанному с использованием ИИ.
